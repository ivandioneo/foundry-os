# Architecture Decision Records (ADR)

Every significant, hard-to-reverse decision gets an ADR. Copy `0000-template.md`,
increment the number, and open it in the PR that implements the decision.

Status lifecycle: Proposed → Accepted → (Superseded by ADR-XXXX | Deprecated).

Link each ADR back to the Story or Epic Issue that prompted it (`Related` field in
the template) — traceability from decision to authorization is mandatory
(`AGENTS.md` §5). See `docs/engineering/STORY_TEMPLATE.md` and
`docs/product/EPIC_TEMPLATE.md` for how Stories and Epics are authorized.
