# Documentation

Engineering, product, and security knowledge for Foundry. Documentation explains
**intent**; code explains itself.

| Folder          | Purpose                                                           |
| --------------- | ----------------------------------------------------------------- |
| `adr/`          | Architecture Decision Records — one file per significant decision |
| `architecture/` | System, data, and component architecture                          |
| `engineering/`  | Standards, conventions, workflows, runbooks                       |
| `product/`      | Product requirements, personas, scope                             |
| `security/`     | Security architecture, threat models, policies                    |

## Start here

- [`product/ROADMAP.md`](./product/ROADMAP.md) — what's being built and why, tied to
  approved GitHub Issues
- [`engineering/AI_DEVELOPMENT_WORKFLOW.md`](./engineering/AI_DEVELOPMENT_WORKFLOW.md) —
  how a Story goes from Issue to merged PR
- [`engineering/DEFINITION_OF_READY.md`](./engineering/DEFINITION_OF_READY.md) — when a
  Story is ready to implement
- [`adr/README.md`](./adr/README.md) — how architectural decisions are recorded
