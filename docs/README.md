# Documentation

Engineering, product, and security knowledge for Foundry. Documentation explains
**intent**; code explains itself.

| Folder | Purpose |
|---|---|
| `adr/` | Architecture Decision Records — one file per significant decision |
| `architecture/` | System, data, and component architecture |
| `engineering/` | Standards, conventions, workflows, runbooks |
| `product/` | Product requirements, personas, scope |
| `security/` | Security architecture, threat models, policies |
