# Security Policy

## Reporting a vulnerability
**Do not open public issues for security problems.** Report privately via GitHub
Security Advisories (Security → Report a vulnerability) or email `security@REPLACE_ME`.

We aim to acknowledge within **72 hours** and will coordinate a fix and disclosure timeline with you.

## Supported versions
Pre-release: only `main` is supported.

## Scope & principles
Foundry follows Security by Design, Privacy by Design, Least Privilege, and
Defense in Depth. Never commit secrets. Production secrets use dedicated secret
management (not environment files).
